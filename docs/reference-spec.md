## 메뉴
프로젝트 관리 / 원본으로 쇼츠 만들기 / 유튜브 데이터 분석(소스 발굴·인기영상·채널분석) / 채널 설정 / 구독·크레딧

## 원본으로 쇼츠 만들기 파이프라인
1. 원본 업로드: mp4·mov·mkv·webm, 최대 6개, 합 90분, 파일당 4GB. 외부 사이트 다운로드 없음. 30일 뒤 삭제.
2. 스타일 카드 선택 → 세부 12단계(언어·화면틀·상단문구·자막·댓글카드·강조효과·나레이션·효과음/BGM·이야기틀·대본직접·처리방식·마무리). 채널 템플릿 저장.
3. 처리 옵션: 길이 20~59초(기본 58), 속도(기본/빠르게), 품질(표준/최고), 검수 횟수(3/1), 발화자막 양.
4. 제작: AI가 원본 분석 → 나레이션 대본 + 헤드라인 2행 + 유튜브 제목 → (대본 먼저 확인 ON이면 여기서 멈추고 사용자가 수정/승인) → 컷 설계 → 자막·댓글카드·강조효과·효과음 → 렌더 → 자기검수.
5. 결과: mp4, 썸네일, 업로드 문안(제목·설명·태그), 캡컷 zip, 타임라인 편집 가져오기.
6. 작업 상태: 대기/진행/대본확인대기/완성/실패/취소. 실패 시 단계부터 재시도. 대기 72시간 초과 시 취소.
7. 별도 모드: 완성 쇼츠 언어만 바꾸기(전사→번역→재렌더, 좌우반전 옵션).
